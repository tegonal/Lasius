# Plane Credentials Setup

## How to create an API key

1. Log into your Plane account or self-hosted instance
2. Go to **Profile Settings**
3. Select "Personal Access Tokens" from the list of tabs
4. Click "Add personal access token"
5. Enter a token name and optional description
6. Click "Generate" or "Create"
7. Copy the generated token immediately and store it securely

<Warning>The token will only be shown once</Warning>

## Workspace slug

You also need your **workspace slug**, which can be found in your Plane URL. For example, if your Plane URL is `https://app.plane.so/my-company`, then your workspace slug is `my-company`.

<Tip>The workspace slug is required to access projects and issues in your workspace</Tip>
